# Zhenyu Zhang · Engineering Portfolio

公开网址为 https://zhenyuz6.github.io/portfolio/ 。

本版包含九个项目的英文简介、技术说明、结果和配图，已加入新提供的实验照片和 CNT 打印视频截帧。所有页面内容集中在 portfolio-data.js。图片放在 assets 文件夹中。

## 预览

解压后双击 index.html，用 Chrome 或 Edge 打开。点击左侧目录可跳到对应项目，点击图片可查看原尺寸。

## 更新现有 GitHub 网站

1. 进入 https://github.com/zhenyuz6/portfolio 。
2. 在 Code 页点 Add file → Upload files。
3. 将解压后的 index.html、portfolio-data.js、portfolio.js、styles.css、README.md、MATERIALS_NEEDED.md 和整个 assets 文件夹拖入。文件应位于仓库根目录，assets 保留文件夹层级。
4. 点 Commit changes。部署完成后刷新公开网址。无需再次设置 GitHub Pages。

MATERIALS_NEEDED.md 是后续图片清单，网站主页通过 index.html 展示。

## 导出 PDF

点 Print / Save as PDF，在打印窗口选择另存为 PDF。建议 Letter 纸张，关闭浏览器页眉和页脚。打印样式按项目分页，并选用代表图。补充新图片后可在打印预览检查图与图注。

## 修改内容

在 portfolio-data.js 中搜索项目 id 或英文标题。summary 是简介，design 是技术说明段落，figures 是图片与图注，results 是结果或当前状态，links 是相关网址。空字段自动隐藏。

图片路径示例为 ./assets/ece445/board.jpg。文件名和路径大小写需要与实际文件一致。
